## 已修复

- EU 仅有点评审核读权限的账号打开待审列表时返回 500：空 SLA 配置被拼成 `CASE ELSE 1 END`，现仅在有配置时生成 CASE，普通审核按提交时间与 ID 排序。
- 跨内容类型超时队列可同时按负责人筛选，并保持区域及权限约束。
- 管理端切换区域或筛选时，旧响应及旧错误不再覆盖新结果；切换区域清空旧内容与输入。
- 保留原有 SLA 剩余/超时显示，使用数据库相对秒数与浏览器单调时钟更新，消除固定北京时间假设和设备时钟校准影响；从请求开始计时，慢响应不延长认领租期。断网后倒计时继续，租期到期即隐藏审核操作。
- 常规 CI 纳入真实后端浏览器 E2E。接口失败会直接断言响应，避免被误报成 30 秒等待超时。
- 修复实际打包暴露的目录错误：用户 Web 应位于 `web/dist/`，不能打成 `web/__base-web-dist/`；临时基础/SEO 构建目录不进入 ZIP。新增集成测试用隔离的构建夹具实际执行打包，校验普通包、双区域 SEO 包、清单与迁移校验和。
- 修正 MySQL smoke 的认领前置流程、SQL 文件参数契约及 Stripe 预检测试夹具；增加真实 MySQL 下受限审核员查询及相对时间字段验证。

新增时间字段为响应扩展：`ageSeconds`、`claimRemainingSeconds`、`oldestPendingAgeSeconds`，无需数据库迁移。原始日期字符串保留用于展示；这次修复不解决门店预订的当地时区建模。
