# 团购标题搜索验证

日期：2026-10-23。基于主干 `e9f799891fab1672ffcc6cfe5d9a90ac88b0fc90`。

MySQL 与 Elasticsearch 门店搜索均支持团购标题，限定同区域审核通过、上架且未删除的套餐。同一门店多个标题只返回一个门店。商户创建、审核、编辑、上下架和换店通过事务 outbox 刷新索引；业务回滚不会留下搜索任务。ES 的 `dealTitles` 字段加入全文查询，批量索引采用 UTF-8。

30 项聚焦测试已通过，包含换店刷新两个门店、回滚不投递，以及旧标题和非公开套餐隔离。真实 Elasticsearch 8.15.5 smoke 通过中英文、拼音与纠错、距离、巴黎单城、跨区域，以及创建 → 审核 → 上架 → 改名重审 → 下架 → 驳回生命周期。首次使用既有本地测试实例时，Docker 数据盘水位阻止分片分配，索引创建读取超时；改用本次专用的 tmpfs 实例完成验收，未调整其他实例配置，完成后已清理。

原有 ES 索引在部署后需执行管理端 `POST /api/admin/v1/search/reindex`，再确认同步队列排空以及中英文标题检索。最终交付以合入后同一 SHA 的完整 CI 和新候选为准。本机日志保存在 `reports/deal-title-search-2026-10-23/`。
